Você tem agora um blog pronto para DOMINAR o Google. Aqui está o manual prático.

**Agora:** Primeira imagem do post HTML aparece automaticamente

Em CADA post que você publica, automaticamente aparece uma seção com 15 links para:
- Gartner, Google Cloud, AWS, McKinsey, Forbes, etc.

**Impacto SEO:** Aumenta autoridade de domínio e relevância temática

## 📝 PASSO A PASSO: CRIAR POST VENCEDOR

### **PASSO 1: Acesse o Admin de Blog**

1. Faça login em `https://seu-site.com/auth`
2. Vá para `/crm`
3. Clique no botão **"Blog"** (azul)
4. Você está em `/blog-admin`

### **PASSO 2: Clique em "Novo Post"**

Aparecerá um formulário com campos.

---

## 📋 CAMPOS DO FORMULÁRIO - PREENCHIMENTO OTIMIZADO

### **Campo: TÍTULO**

📌 **Regra de Ouro:**
- Entre 50-60 caracteres (máximo ideal do Google)
- Inclua palavra-chave PRINCIPAL
- Seja específico e atrativo

✅ **Bom:**
```
"Automação com IA: Guia para Reduzir Custos 60% em 2024"
```

❌ **Ruim:**
```
"Blog post sobre tecnologia"
```

⚡ **Dica:** Use palavras como:
- Guia
- Como
- Estratégia
- Método
- Tudo sobre
- Números (5, 10, 20)

---

### **Campo: SLUG (URL)**

📌 **Gerado automaticamente**, mas você pode ajustar

**Fórmula:**
- Minúsculas
- Separadas por hífen
- Sem acentos
- Inclua palavras-chave

✅ **Exemplo:**
```
automacao-ia-reducao-custos-2024
```

**Resultado URL:**
```
https://seu-site.com/blog/automacao-ia-reducao-custos-2024
```

---

### **Campo: RESUMO (Excerpt)**

📌 **Crucial para CTR (Click-Through Rate)**

Este é seu **meta description** que aparece no Google!

**Regra:**
- Entre 120-160 caracteres
- Responda: "Por que alguém clicaria?"
- Inclua palavra-chave
- Tenha Call-to-Action implícito

✅ **Exemplo:**
```
Descubra como automatizar processos com IA pode reduzir custos operacionais em até 60%. Guia completo com 5 estratégias comprovadas para sua empresa.
```

**Teste:** Conte os caracteres (máximo 160)

---

### **Campo: CONTEÚDO HTML**

📌 **Aqui é onde a mágica acontece**

**Estrutura Obrigatória:**

```html
<h1>Seu Título Exato Aqui</h1>

<p>Primeiro parágrafo introdutório com a palavra-chave principal nos primeiros 100 caracteres.</p>

<!-- IMPORTANTE: Primeira imagem deve estar aqui -->
<img src="https://cdn.seu-dominio.com/imagem-principal.jpg" alt="Descrição da imagem para SEO">

<h2>Subtítulo 1</h2>
<p>Conteúdo do primeiro subtópico...</p>

<h2>Subtítulo 2</h2>
<p>Conteúdo...</p>
<ul>
  <li>Ponto 1</li>
  <li>Ponto 2</li>
  <li>Ponto 3</li>
</ul>

<img src="https://cdn.seu-dominio.com/imagem-2.jpg" alt="Descrição">

<h2>Subtítulo 3</h2>
<p>Mais conteúdo...</p>

<h3>Sub-subtítulo se necessário</h3>

<!-- Mais imagens a cada 300-400 palavras -->

<h2>Conclusão</h2>
<p>Resumo e chamada para ação.</p>
```

**Regras de Ouro:**

✅ **FAÇA:**
- Uma `<h1>` (o título do post)
- Mínimo 3-5 `<h2>` (subtítulos)
- Mínimo 4-6 imagens
- Mínimo 1500 palavras (melhor 2000+)
- Links internos (para /diagnostico-gratuito)
- Lista com 4+ itens (Google adora para featured snippets)
- Alt tags descritivos em imagens

❌ **EVITE:**
- Múltiplos `<h1>` (confunde o Google)
- Parágrafos muito longos (quebra a cada 3-4 frases)
- Imagens sem alt text
- Links mortos ou spam
- Cópias de outros sites (Google detecta)

## 📊 O QUE ACONTECE AUTOMATICAMENTE

Quando você publica um post, TUDO ISSO é automático:

✅ **Na Listagem do Blog** (`/blog`):
- Primeira imagem aparece no card
- Resumo apareça
- Data publicação
- Tempo de leitura calculado

✅ **Na Página do Post** (`/blog/seu-slug`):
- Título em `<h1>` para SEO
- Meta tags Open Graph (para redes sociais)
- Schema.org JSON-LD injetado (para Google)
- 15 backlinks estratégicos em seção fixa
- Compartilhamento em redes sociais
- CTA para diagnóstico no final

✅ **No Google Search Console:**
- Post indexado automaticamente
- Rich snippets habilitados
- Imagem aparece em busca

- Google Search Console: Veja em quais palavras você está aparecendo

## 🐛 TROUBLESHOOTING

### "Primeira imagem não aparece no card"

**Solução:** Certifique-se que a imagem está com `<img>` tag no HTML:
```html
<img src="https://dominio.com/imagem.jpg" alt="Descrição">
```

### "Não vejo os 15 backlinks"

**Solução:** Estão AUTOMÁTICAMENTE após o conteúdo. Rolagem até o final da página.

### "Não aparece no Google"

**Passos:**
1. Google Search Console → Submeter URL
2. Aguarde 1-3 dias
3. Verifique se está indexado

### "Conteúdo HTML não renderizando"

**Solução:** Valide seu HTML:
- Abra browser → F12 → Console
- Procure por erros
- Tags abertas sem fechamento? Feche!

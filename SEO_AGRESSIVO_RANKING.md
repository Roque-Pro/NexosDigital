## 🎯 ESTRATÉGIA DE RANKING - CHECKLIST PARA POSTS

Quando você cria um novo post, siga este checklist para MÁXIMO RANKING:

### **A. ESTRUTURA DO CONTEÚDO**

- [ ] **Título**: 50-60 caracteres, include palavra-chave principal
  - Exemplo: "Automação com IA: 5 Estratégias para Reduzir Custos 60%"

- [ ] **Slug**: URL-friendly, com palavras-chave
  - Exemplo: `automacao-ia-reducao-custos`

- [ ] **Meta Description (Excerpt)**: 120-160 caracteres
  - Deve incentivar clique e conter palavra-chave

- [ ] **Primeira Imagem**: Obrigatória, alta qualidade (1200x630 px)
  - Aparecerá nos cards e compartilhamentos

### **B. CONTEÚDO OTIMIZADO**

- [ ] **Comprimento**: Mínimo 1500 palavras (melhor 2000+)
  - Google favorece conteúdo profundo e detalhado

- [ ] **Um H1**: Apenas um título principal (igual ao título do post)
  - `<h1>Seu Título Aqui</h1>`

- [ ] **H2 Subtítulos**: Mínimo 3-5 subtítulos
  - Estrutura clara do conteúdo

- [ ] **H3 Sub-subtítulos**: Onde apropriado
  - Melhor legibilidade e hierarquia

- [ ] **Parágrafos**: Máximo 3-4 frases cada
  - Melhor para mobile e leitura rápida

- [ ] **Listas (UL/OL)**: Mínimo 2 listas com 4+ itens
  - Featured snippets adoram listas

### **C. PALAVRAS-CHAVE (KEYWORDS)**

- [ ] **Primary Keyword**: Principal, deve aparecer no título e primeiras 100 palavras
  - Frequência natural: 1-2% do texto

- [ ] **Long-tail Keywords**: Variações e frases longas
  - Exemplo: "como automatizar processos com IA", "ferramentas RPA 2024"

- [ ] **Semânticas**: Sinônimos e termos relacionados
  - Google entende contexto, não precisa ser exato

- [ ] **Temas Cobertos**:
  - ✓ Automação
  - ✓ Inteligência Artificial
  - ✓ Tecnologia
  - ✓ Transformação Digital
  - ✓ Otimização de Processos

### **D. IMAGENS E MÍDIA**

- [ ] **Mínimo 4-6 imagens** no conteúdo
  - Uma a cada 300-400 palavras

- [ ] **Alt Text**: Cada imagem tem descrição relevante
  - `<img src="..." alt="Diagrama de automação RPA com IA">`

- [ ] **Nomes de arquivo**: Descritivos, não "img001.jpg"
  - Exemplo: `automacao-rpa-workflow.jpg`

- [ ] **Tamanho otimizado**: Comprimidas, não pesadas
  - Máximo 500KB por imagem

### **E. LINKS (BACKLINKS E INTERNOS)**

- [ ] **Links Externos**: Mínimo 5-10 para autoridades
  - Já incluído: 15 backlinks estratégicos na seção

- [ ] **Links Internos**: Mínimo 3-5 para outras páginas
  - Exemplo: `/diagnostico-gratuito`, `/blog`, outras posts

- [ ] **Anchor Text**: Descritivo, contém palavras-chave
  - ✓ Bom: "automação de processos"
  - ✗ Ruim: "clique aqui"

- [ ] **Links no contexto**: Naturais, não forçados
  - Devem fazer sentido dentro do parágrafo

### **F. TÉCNICAS AVANÇADAS**

- [ ] **FAQ Section**: Se aplicável, Q&A estruturado
  ```html
  <h3>Perguntas Frequentes</h3>
  <h4>O que é automação com IA?</h4>
  <p>Resposta...</p>
  ```

- [ ] **Statistics/Data**: Dados, números, pesquisas citadas
  - "Segundo Gartner, 82% das empresas..."

- [ ] **Código/Exemplos**: Se relevante, código formatado
  ```html
  <pre><code>seu_codigo_aqui</code></pre>
  ```

- [ ] **Tabelas**: Comparativos, quando apropriado
  - Google adora estruturar dados em tabelas

### **G. MOBILE OPTIMIZATION**

- [ ] **Responsivo**: Testa em smartphone
- [ ] **Velocidade**: Imagens otimizadas
- [ ] **Legibilidade**: Texto grande o suficiente (16px+)
- [ ] **CTA**: Botão de ação visível no mobile

## 🎯 RANKING AGRESSIVO - TÁTICA AVANÇADA

### **Velocity Strategy** (Publicação Rápida)
- Publique 3-4 posts por semana inicialmente
- Google favorece sites com atualização frequente
- Depois mantém 1-2 por semana para consistência

### **Cluster Topics** (Grupos de Posts)
- Crie 5-10 posts sobre **Automação**
- Crie 5-10 posts sobre **IA e Machine Learning**
- Crie 5-10 posts sobre **Transformação Digital**
- Link cruzado entre posts do mesmo cluster
- Google reconhece você como autoridade em cada tópico

### **Featured Snippet Targeting**
- Responda perguntas de forma clara e direta
- Use listas numeradas (Google adora)
- Use tabelas para comparativos
- Máximo 40-60 palavras para snippet estar elegível

### **Internal Link Strategy**
```
Blog Post A (Automação com IA)
  ↓
  Links para → Diagnostico Gratuito
  Links para → Blog Post B (RPA)
  Links para → Blog Post C (Transformação Digital)
```

### **Social Signals** (Amplificação)
- Compartilhe cada post em:
  - LinkedIn (para B2B, muito importante)
  - Facebook
  - Twitter/X
  - WhatsApp (seu círculo)
- Pedir compartilhamento em email newsletters

## 📈 MÉTRICAS PARA ACOMPANHAR

### Google Search Console
- [ ] Impressões: Quantas vezes aparece nos resultados
- [ ] CTR (Click-Through Rate): Quando mais, melhor
- [ ] Posição média: Objetivo é top 3

### Google Analytics
- [ ] Usuários do blog
- [ ] Taxa de rejeição: Menos é melhor
- [ ] Tempo médio na página: Mais é melhor
- [ ] Conversão para diagnóstico

### Rankings
- Use SEMrush, Ahrefs ou Ubersuggest
- Rastreie posição de palavras-chave principais
- Objetivo: Top 10 em 3 meses, Top 3 em 6 meses

❌ Conteúdo copiado/genérico
✅ Conteúdo único, experiência pessoal/dados

❌ Sem imagem ou imagem ruim
✅ Primeira imagem relevante e profissional (1200x630)

❌ Links mortos ou irrelevantes
✅ Backlinks para autoridades reais no tema

❌ Atualização nunca
